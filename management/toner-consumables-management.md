# Printer Toner & IT Consumables Management

Toner and other consumables are small purchases individually, but poor stock control can cause avoidable downtime and emergency spending. Track actual usage and compatible supplies by printer model.

## Scope

Depending on the environment, the register may cover toner cartridges, ink, drums, fuser units, maintenance kits, labels, receipt paper, cleaning supplies, patch cords, SFPs and other frequently used spares.

## Consumables register

| Field | Purpose |
|---|---|
| Item code | Unique stock reference |
| Item description | Toner model, cartridge type or consumable |
| Compatible printer/device models | Avoid incorrect purchases |
| OEM / approved compatible | Record approved supply type |
| Unit of measure | Piece, box, pack |
| Opening balance | Stock at period start |
| Received quantity | Goods received |
| Issued quantity | Quantity issued to a site or device |
| Closing balance | Reconciled stock |
| Minimum / reorder level | Trigger for replenishment |
| Supplier / lead time | Reorder planning |
| Batch / expiry | Where applicable |
| Storage location | Controlled stock location |

## Reorder planning

Set a reorder point using actual consumption and supplier lead time:

`Reorder point = Average usage during lead time + Safety stock`

For example, if average usage is 4 cartridges per month and replenishment takes half a month, expected lead-time demand is about 2 cartridges. Add safety stock based on delivery reliability and the criticality of the printers. This is an illustrative calculation, not a fixed stock policy.

## Issue and return controls

- Record each issue against a device, site or authorized user.
- Check cartridge compatibility before issue.
- Record defective, leaking or unused returned items.
- Rotate stock and follow manufacturer storage guidance.
- Separate genuine, approved compatible and rejected stock.
- Investigate unusually high consumption or repeated print-quality failures.
- Reconcile physical balance with the stock register.

## Cost and usage review

Review monthly usage by printer model, department or site where appropriate. Consider page volume, coverage, cartridge yield, cost per page, service calls and device age. A low cartridge price may not provide the lowest total cost if yield or print quality is poor.

## Monthly review

- Opening and closing balance.
- Receipts, issues and adjustments.
- Stock below reorder point.
- Slow-moving or obsolete items.
- Emergency purchases and stock-outs.
- Device-level usage exceptions.
- Forecast requirement and approval.

Do not publish supplier prices, internal consumption by department or sensitive user-level print records in a public portfolio.
