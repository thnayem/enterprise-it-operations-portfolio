# IT Asset & Inventory Management

An accurate inventory helps IT understand what it owns, where equipment is used, who is responsible for it, what it costs to support and when it should be replaced. The register should be maintained throughout the asset lifecycle, not created only for an annual audit.

## Asset lifecycle

1. **Request:** record the business need and required specification.
2. **Approval:** confirm budget, authority and procurement route.
3. **Receipt:** inspect quantity, model, condition and supplied accessories.
4. **Register:** assign an asset ID and record warranty and ownership details.
5. **Deploy:** record user or service assignment, location and configuration baseline.
6. **Maintain:** track repairs, upgrades, movement, software and warranty events.
7. **Audit:** reconcile the register with physical assets and finance records.
8. **Retire:** obtain approval, remove access and data securely, then update records.

## Suggested asset register

| Field | Purpose |
|---|---|
| Asset ID / tag | Unique internal identifier |
| Asset category | Laptop, desktop, switch, router, server, printer, UPS, phone, etc. |
| Manufacturer / model | Identification and compatibility |
| Serial number | Store in the controlled internal register only |
| Purchase / receipt date | Lifecycle and financial reference |
| Supplier / PO reference | Procurement traceability |
| Cost / cost centre | Finance reconciliation; restrict access as needed |
| Site / room | Physical location |
| Assigned user / service owner | Accountability |
| Warranty / support expiry | Renewal and replacement planning |
| Status | In stock, deployed, spare, repair, loan, retired |
| Condition | New, good, damaged, under repair |
| Configuration / version | Support and compatibility |
| Last verified date | Audit confidence |

## Inventory controls

- Use a consistent asset ID format and label equipment where appropriate.
- Record transfers, loans, returns and repairs promptly.
- Separate physical stock from deployed assets.
- Set minimum and maximum stock levels for critical spares.
- Reconcile purchase orders, goods received, asset register and finance records.
- Restrict sensitive fields and maintain an audit trail.
- Investigate missing, duplicate or unassigned assets rather than silently correcting records.
- Keep software licenses and subscriptions in a related entitlement register.

## Audit approach

Plan periodic physical verification based on risk and asset type. Check a sample or full population according to organizational policy. Record the asset ID, observed location, condition, custodian, discrepancy and corrective action.

## Secure retirement

Before disposal or reassignment:

- Obtain required approval.
- Back up or transfer business data under the retention policy.
- Remove accounts, certificates, keys and management access.
- Sanitize storage using an approved method appropriate to the media.
- Record disposal, return-to-vendor or recycling evidence.
- Update inventory, finance and access records.

Do not publish serial numbers, assigned-user details, internal locations, purchase prices or management addresses in a public repository.
